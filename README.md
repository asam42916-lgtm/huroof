# حروف المناسبة

لعبة خلايا الحروف للمناسبات الشخصية — تُدار من جوال المقدّم وتشتغل بدون نت بعد أول فتح.

## الروابط
- `/demo/` — نسخة تجريبية بأسئلة مثال.
- `/form/` — نموذج الأسئلة اللي يعبّيه صاحب المناسبة ويرسل النص الناتج.

## إضافة عميل جديد
1. انسخ مجلد `demo` باسم العميل، مثلًا `ahmad`.
2. افتح `ahmad/app.js` واستبدل الجزء اللي بين «إعدادات اللعبة» و«نهاية الإعدادات» بالنص اللي وصلك من النموذج.
3. ارفع التغييرات، والرابط يصير: `https://asam42916-lgtm.github.io/huroof/ahmad/`
